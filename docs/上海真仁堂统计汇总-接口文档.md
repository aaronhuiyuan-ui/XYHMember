# 上海真仁堂统计汇总 查询接口文档

> 供第三方（OA 系统等）拉取「加工费及快递费汇总」页面导入的月度统计数据。
> 本接口**免登录**，通过请求头 `X-Api-Key` 校验访问密钥。

---

## 一、基本信息

| 项目 | 说明 |
| --- | --- |
| 接口地址 | `http://172.68.1.12:8080/OaApi/GetZhenRenTangStats` |
| 请求方式 | **POST**（仅支持 POST，GET 不可用） |
| 数据格式 | JSON（UTF-8） |
| 鉴权方式 | 请求头 `X-Api-Key: <密钥>` |
| 数据来源 | `fghis5..上海真仁堂统计汇总` 表（「加工费及快递费汇总」页面「导入到OA」写入） |

> ⚠️ 端口为 `8080`，非 80。

---

## 二、鉴权说明

调用方必须携带访问密钥，两种传法任选其一：

1. **推荐**：请求头
   ```
   X-Api-Key: zrt-oa-2026
   ```

2. 兼容方式：标准 Bearer 请求头
   ```
   Authorization: Bearer zrt-oa-2026
   ```

> 密钥由我方线下提供。密钥错误或缺失时，接口返回 `{"success":false,"msg":"无效的访问密钥"}`。

---

## 三、请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `month` | string | 否 | 月份，格式 `yyyy-MM`，如 `2026-08`。可放在**查询字符串**或**表单 body** 中。省略时返回全部月份（按月份倒序） |

示例请求参数形式（等价）：

- 查询字符串：`POST /OaApi/GetZhenRenTangStats?month=2026-08`
- 表单 body：`POST /OaApi/GetZhenRenTangStats`，body = `month=2026-08`

## 四、返回说明

### 4.1 成功

```json
{
  "success": true,
  "data": [
    {
      "序号": 4,
      "月份": "2026-07",
      "应付加工费": 4257.18,
      "应付快递费": 470.00,
      "导入时间": "\/Date(1786609765923)\/"
    }
  ]
}
```

### 4.2 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `data` | array | 数据列表，按 `月份` 倒序排列 |
| `data[].序号` | number | 自增主键 |
| `data[].月份` | string | 统计月份，格式 `yyyy-MM` |
| `data[].应付加工费` | number | 该月应付加工费（合计） |
| `data[].应付快递费` | number | 该月应付快递费（合计） |
| `data[].导入时间` | string | 导入时间（微软 JSON 日期格式，形如 `\/Date(毫秒时间戳)\/`） |

> `导入时间` 为 .NET 序列化的日期格式。如需普通时间，可解析括号内毫秒时间戳：`new Date(1786609765923)`。
> 若某月份尚未导入，`data` 为空数组 `[]`，`success` 仍为 `true`。

### 4.3 失败

| 场景 | 返回 |
| --- | --- |
| 密钥缺失或错误 | `{"success":false,"msg":"无效的访问密钥"}` |
| 服务异常 | `{"success":false,"msg":"<异常信息>"}` |

## 五、调用示例

### 5.1 curl

```bash
# 查询指定月份
curl -X POST "http://172.68.1.12:8080/OaApi/GetZhenRenTangStats" \
  -H "X-Api-Key: zrt-oa-2026" \
  -d "month=2026-07"

# 查询全部月份
curl -X POST "http://172.68.1.12:8080/OaApi/GetZhenRenTangStats" \
  -H "X-Api-Key: zrt-oa-2026" \
  -d ""
```

> ⚠️ **注意**：POST 请求必须带 body（哪怕为空 `-d ""`），否则 IIS 会返回 HTTP 411「Length Required」。

### 5.2 JavaScript（fetch）

```javascript
const res = await fetch('http://172.68.1.12:8080/OaApi/GetZhenRenTangStats', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded', 'X-Api-Key': 'zrt-oa-2026' },
  body: 'month=2026-07'
});
const json = await res.json();
if (json.success) {
  console.log(json.data);
} else {
  console.error(json.msg);
}
```

### 5.3 C#（HttpClient）

```csharp
using (var client = new HttpClient())
{
    client.DefaultRequestHeaders.Add("X-Api-Key", "zrt-oa-2026");
    var content = new FormUrlEncodedContent(new[] {
        new KeyValuePair<string, string>("month", "2026-07")

    var resp = await client.PostAsync(
        "http://172.68.1.12:8080/OaApi/GetZhenRenTangStats", content);
    var json = await resp.Content.ReadAsStringAsync();
}
```

### 5.4 Java（OkHttp）


## 六、常见问题

1. **为什么报 411？** 服务器为 IIS，POST 请求必须包含 body（Content-Length 不能为空）。用 curl 时请加 `-d ""` 或实际参数。
2. **返回「无效的访问密钥」？** 请确认请求头名称 `X-Api-Key` 拼写正确、密钥与我方提供的一致。
3. **查不到某月数据？** 该月尚未在「加工费及快递费汇总」页面执行「导入到OA」。需足月查询（整月 1 日~月末）后才能导入。
4. **同一月份可以导入多次吗？** 不可以。重复导入会提示「该月份已导入」，需先删除表中该月数据。
